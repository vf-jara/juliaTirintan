# Júlia Tirintan · Arquitetura & Interiores

Landing page estática (HTML + CSS + JS puro, sem build). Para visualizar, abra `index.html` no navegador.

```
index.html          estrutura e textos
css/styles.css      paleta, tipografia e layout (tokens em :root)
js/main.js          menu, animações, filtro, lightbox, antes/depois, formulário
assets/img/         imagens
```

## Antes de publicar

1. **Fotos:** as imagens em `assets/img/` são recortes provisórios (baixa resolução) tirados de prints do Instagram.
   Substitua pelos arquivos originais, mantendo o mesmo nome.
2. **Antes & depois:** adicione `assets/img/veraneio-antes.jpg` e `assets/img/ap-ld-antes.jpg`.
   Enquanto não existirem, o comparador mostra um espaço reservado.
3. **WhatsApp:** preencha `CONFIG.whatsapp` em `js/main.js` (ex.: `"5567999999999"`).
   Sem o número, o formulário e o botão flutuante levam ao Linktree.
4. **Depoimentos:** troque os textos entre colchetes na seção `#feedbacks` do `index.html`.
5. **Revisar textos:** serviços, etapas do processo e descrições dos projetos foram escritos a partir do perfil.
   Ajuste o que não refletir a forma de trabalho da Júlia.
